 # 📊 FAANG Stocks Market Analysis & Power BI Dashboard

An end-to-end data analytics project examining historical stock market data, trading volumes, and price performance for FAANG tech giants (Facebook, Amazon, Apple, Netflix, Google). Developed by **Team 4**.

---

### 📂 Repository Files
* **FAANG.ipynb**: Data cleaning, preprocessing, and ETL pipeline.
* **EDA (2).ipynb**: Exploratory Data Analysis and statistical visualizations.
* **FAANG_Stocks_Market_Overview_Team4.pbix**: Interactive Power BI Dashboard file.
* **FAANG_Stocks_Executive_Presentation.pptx**: Project presentation deck for executive stakeholders.

---

### 📌 Executive Summary & Key KPIs
* **Total Volume**: 4T
* **Average Close**: $190.43
* **Average Range**: $4.26
* **Average Change (%)**: 0.04%

---

### 📈 Key Dashboard Features
* **Executive KPI Cards**: Quick summary of market metrics.
* **Close Price Trajectory**: Historical trend line tracking long-term price movements.
* **Volume Accumulation**: Area chart displaying volume cycles over time.
* **Volatility & Market Share**: Comparative bar and donut charts for price ranges and trading share.
* **Detailed Financial Matrix**: Table with dynamic unit formatting (B / T) for granular analysis.
